# 藥局搜尋的資料缺口：藥妝店門市查不到

記錄日期：2026-09-30
狀態：未處理

## 現象

- 在基隆搜尋「康是美」，最近的結果是汐止的「康是美北峰藥局」（距基隆車站 13.6 公里）。Google Map 上基隆市區有多家康是美。
- 輸入「基隆康是美」回「查無此院所資料」。

## 原因

搜尋邏輯沒有問題，是藥局庫沒有這些門市。

藥局庫（`medical_facilities_pharmacy`，7,970 筆）收的是健保特約藥局，`type` 只有「藥師自營」「藥劑生自營」。康是美、屈臣氏的多數門市是藥妝店，登記的不是藥局，所以不在裡面。

2026-09-30 查到的數字：

| 項目 | 筆數 |
|---|---|
| 藥局庫裡地址在基隆的藥局 | 119 |
| 其中康是美 | 0 |
| 藥局庫裡全台的康是美 | 107（分布 15 個縣市，基隆、花蓮、臺東沒有） |
| 藥局庫裡全台的屈臣氏 | 1（屈臣氏景安門市） |
| 基隆有收錄的連鎖 | 佑全 2 家、義一啄木鳥藥局 1 家 |

## 找過的資料來源

| 來源 | 內容 | 能不能補藥妝店 |
|---|---|---|
| [食藥署「藥局基本資料」](https://data.gov.tw/dataset/6134) | 全台藥局 9,155 筆，含非健保特約；有名稱、地址、電話、是否特約；政府資料開放授權 | 不能 |
| [商工行政「商業登記－西藥零售業」](https://data.gcis.nat.gov.tw/od/detail?oid=060DE43D-6CE7-41B1-9185-D00E4C80DABB) | 統編、商業名稱、地址、登記狀態；每月更新 | 大概不能（只看過說明，沒下載驗證） |
| [康是美官網門市查詢](https://www.cosmed.com.tw/shop.aspx) | 各門市名稱、地址、電話 | 能，但不是開放資料 |

食藥署那份下載驗證過（[CSV](https://data.fda.gov.tw/data/opendata/export/35/csv)）：

- 健保特約 7,605、非特約 1,272、未標示 278，比藥局庫多約 1,500 家非特約藥局。
- 基隆市 131 家，康是美仍是 0 家。
- 康是美全台 92 筆；屈臣氏、松本清、日藥本舖、Tomod's、寶雅都是 0 筆。
- 沒有經緯度與營業時間。

藥妝店在法規上屬於西藥販賣業藥商，沒有找到這類藥商的開放資料集。

## 待辦

1. **「地區＋店名」在該地區查無時退一步**：目前「基隆康是美」直接回查無，但「康是美」會回最近的汐止門市。改成該地區查無時只用店名、依距離找最近的。只動藥局的名稱查詢（`build_pharmacy_query`／`find_pharmacy_by_name`），院所不動。
2. **併入食藥署的非特約藥局**（約 1,500 家）：授權乾淨，但要自己做地址轉座標，也沒有營業時間。
3. **藥妝店門市**：只能從各連鎖官網取得。要先確認使用條款，每家連鎖各寫一支，之後還要定期更新。是否要做待決定。
4. **過時文案**：最近的藥局超過 5 公里時，LINE 仍會附上「本系統收錄的藥局資料有限」。這句是藥局只收錄 116 家時寫的，現在收錄 7,970 家，偏遠地區看到這句會被誤導。相關程式在 `app/services/medical/search_summary.py` 與 `location.type.pharmacy_none`、`location.type.pharmacy_data_gap` 兩則訊息；LIFF 的 `pharmacy_data_gap_meters` 欄位是前端合約，要一起處理。
