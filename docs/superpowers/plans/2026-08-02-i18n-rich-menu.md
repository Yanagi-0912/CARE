# i18n Rich Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 六語 Rich Menu 建立／ID 保存、熱區 label 在地化、LIFF 改語言時 link 對應選單。

**Architecture:** Layout 純函式負責多語 label＋圖路徑；`RichMenuService` 負責 resolve ID＋LINE link；`UserProfileService` 在 language 變更時呼叫 link；setup 腳本迴圈上傳並寫 `rich_menu_ids.json`。

**Tech Stack:** Python 3.12、pytest、LINE Messaging API、FastAPI

**OpenSpec:** `openspec/changes/i18n-rich-menu/`

## Global Constraints

- 支援語系必須為：`zh-TW`, `en`, `id`, `vi`, `th`, `ja`
- 圖檔：`resources/rich_menu_{language}.png`；IDs 檔：`resources/rich_menu_ids.json`
- Runtime 優先 `RICH_MENU_IDS_JSON` env，否則讀 json 檔
- 未知 language fallback `zh-TW`
- Link 失敗不得讓 settings PATCH 失敗
- 測試用 DI mock，禁止 monkey-patch 改全域 import
- 每完成 task 勾選 `openspec/changes/i18n-rich-menu/tasks.md`
- 勿 stage 無關 RAG／light-crag 檔案

- `class RichMenuService`:
  - `__init__(self, get_access_token: Callable[[], str], menu_ids: dict[str, str] | None = None)`
