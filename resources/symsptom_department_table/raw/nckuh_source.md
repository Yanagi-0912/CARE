# 成大醫院 參考病症一覽表（原文備份）

- 用途：症狀／科別對照表原料，僅供內部整理；正式表的病症描述需人工改寫，不逐字散布

## 內科

| 看診科別 | 參考病症 |
|---|---|
| 一般內科 | 凡十八歲以上覺得身體不舒服者皆可看診。 |
| 胃腸肝膽內科 | 腹脹、腹瀉、大便不規則、食慾不振、胃酸、胃潰瘍、黑便、吐血、肝炎帶原、腹痛、肝機能異常、肝膽結石。 |
| 感染科 | 不明原因發燒、感冒、泌尿道/軟組織感染、性行為相關體傳染病或各種微生物引起之感染症狀。 |
| 胸腔內科 | 咳嗽、咳血、哮喘、肺結核、肺腫瘤、肺炎、支氣管炎等各種肺部疾病。 |
| 血液科 | 各種癌症諮詢、篩檢、診斷、治療及追蹤，各種血液疾病之診斷及治療。 |
| 新陳代謝科 | 甲狀腺疾病、糖尿病、病態肥胖、腦下垂體病變、內分泌異常。 |
| 風濕免疫科 | 關節炎（尿酸痛風性、類風濕性、退化性）、僵直性脊椎炎、各種過敏症、紅斑性狼瘡等自體免疫疾病。 |
| 腎臟科 | 腎臟炎、血尿、尿蛋白、水腫、尿毒症、腎結石、腎臟感染、高血壓。 |
| 心臟血管內科 | 心臟衰竭、心絞痛及心肌梗塞、高血壓或動脈硬化性心臟病、先天性心臟病、心律不整及其他心臟血管疾病。 |
| 毒物科 | 各類中毒病症、一般腎臟疾病、內科急診出院病人。 |
| 職業暨環境醫學科 | 凡現在或過去因工作而感覺身體不適與其工作有相關者，如呼吸、神經系統、肝腎疾病、皮膚疾病與急慢性中毒等各種情況。 |
| 家庭醫學科 | 整個家庭成員常見疾病的診斷和治療，包括高血壓、高血糖、高血脂症、肝炎、甲狀腺疾病、感冒發燒、胃腸疾病、關節炎、腰酸背痛、疲倦、失眠、頭痛、肥胖等。中、英文體檢，預防注射，衛生教育、健康諮詢及各種檢查異常結果之追蹤和治療。 |

## 外科

| 看診科別 | 參考病症 |
|---|---|
| 一般外科 | 一般外傷、乳房有硬塊、裂傷縫合、須動手術者(胃出血、潰瘍、肝腫瘤、膽結石、甲狀腺肥大、盲腸炎)胃腸手術、腸阻塞、疝氣。 |
| 心臟血管外科 | 心臟、周邊血管有關外科疾病：如心臟膜狹窄及閉鎖不全、狹心症、動靜脈阻塞、小兒先天性心臟病手術、靜脈曲張、動靜脈瘻管。 |
| 胸腔外科 | 胸腔、食道有關之外科疾病：如胸腔腫瘤、漏斗胸、肺結核、支氣管擴張（要手術者）、胸部外傷、食道腫瘤或狹窄、胸腔鏡治療狐臭及手汗症。 |
| 腦神經外科 | 車禍腦部撞傷、脊髓外傷、腦瘤、顱內出血、多汗症、狐臭、疼痛（如三叉神經痛、坐骨神經痛)、顏面抽搐、下背痛。 |
| 整型外科 | 唇、顎裂、顏面畸形或腫瘤、乳房重建（乳癌術後）、手部外科、肢體嚴重外傷或潰爛、頭頸部腫瘤、灼（燙）傷、顏面、臂叢神經麻痺重建。美容整形：五官、乳房、腹臀等部位、禿頭、拉皮、抽脂、皮膚需手術者（痣、疤痕）、狐臭。 |
| 大腸直腸肛門外科 | 便血、內外痔、脫肛、便秘、下痢、大便失禁、腹痛、腹脹、肛門痛腫、下腹部腫瘤、大腸癌、直腸肛門癌。(16歲以下請掛小兒外科) |
| 小兒外科 | 凡十五歲以下之小兒疝氣、陰囊水腫、隱睪、尿道下裂、其他泌尿道及生殖道之異常、斜頸、表皮腫瘤、盲腸炎、腹部腫瘤及各種先天性胸腹部異常、肛門閉鎖、巨結腸症等。 |
| 腎臟移植外科 | 尿毒症有關外科手術：動靜脈血管、腹膜透析管植入手術、腎臟移植手術前評估、手術後追蹤。 |

| 復健科 | 骨骼肌肉病變、腰痛、關節疼痛、中風、肌肉疼痛等診斷與治療，腦、脊髓損傷、腦性麻痺、扁平足、內外八字腳、灼(外)傷導致功能或活動障礙之肢體復健、截肢後復健訓練、語言治療、吞嚥治療。 |
| 疼痛科 | 各種急性之疼痛及其他不明原因頑固性疼痛、惡性腫瘤及痛症引起之疼痛。 |
| 神經科 | 凡18歲以上有頭痛、頭暈、癲癇、中風、半身不遂、肌力減退喪失、肢體無力、麻木、背痛、腦炎、腦膜炎、肌肉病變、各種神經痛、肌肉抽搐、手腳顫抖、步調不穩、失語症、意識障礙、痴呆、眼球運動障礙、顏面神經麻痺者。 |

| 眼角膜科 | 角膜結膜病變、乾眼症、化學灼傷、角膜潰瘍、角膜移植、近視開刀及散光矯正等。 |
| 斜弱視科 | 斜、弱視、學齡前兒童眼睛之異常等。 |
| 視網膜科 | 糖尿病及高血壓性視網膜病變、網膜剝離、視網膜裂孔、黃斑部退化、玻璃體出血、玻璃體混濁、飛蚊症等。 |
| 眼屈光科 | 屈光異常（近視、遠視、散光、老花）低視能、視功能異常等。 |

| 葡萄膜炎 | 感染性、外傷性、腫瘤性、自體免疫性葡萄膜炎。 |

## 高齡醫學部

| 看診科別 | 參考病症 |
|---|---|
| 高齡醫學部 | 1. 高齡多重疾病、多重用藥諮詢、周全性老年評估。<br>2. 出現「老年病症候群」，例如跌倒、譫妄、失智、憂鬱、尿失禁、營養不良、體重減輕等。<br>3. 身體功能衰退、日常生活短期間內需要他人協助或照顧，卻仍無確定診斷者。<br>4. 80歲以上長者，需要全面了解健康問題及訂定照護計畫。 |
