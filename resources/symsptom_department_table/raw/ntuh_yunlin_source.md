## 外科部

| 科別 | 參考病症 |
|---|---|
| 普通外科 | 外傷換藥、拆線；皮膚疾病治療(如:脂肪瘤、皮下腫塊、雞眼、皮脂腺囊腫、其他皮膚腫瘤、甲溝炎)。 |
| 神經外科 | 頭痛、噁心嘔吐及視力模糊是顱內壓上升的徵象，可能是腦腫瘤、腦膿瘍、水腦症等，應儘早就醫。意識障礙、半身不遂、下半身麻痺、忽然發生的頸部僵硬及嚴重頭痛可能是腦中風出血或其他神經外科急症，應火速就醫。坐骨神經痛或頸椎痛延伸至手掌是椎間盤突出或骨刺壓迫神經引起的，若服藥、復健無效，仍以手術根本治療為宜、以免神經受壓迫太久而無法復原。頭部外傷、脊椎脊髓外傷、三叉神經痛、背痛、眩暈、手掌多汗症、腕隧道症候群等均可看神經外科醫師。 |
| 大直腸肛門科 | 症狀:大便出血、慢性貧血、長期便秘、腹脹、腹瀉、大便習慣改變、大便變細、大便頻繁、大便失禁、長期性腹痛、肛門腫痛、肛門脫垂、肛門周圍結節或化膿。治療內容:內外痔(橡皮筋結紮法)、肛門膿瘍及廔管、肛裂、下腸胃道出血、脫肛、腸躁症、大腸憩室症、大腸直腸炎、大腸直腸良性腫瘤、大腸直腸癌高危險群篩檢、大腸直腸惡性腫瘤、大腸鏡檢。 |
| 乳房甲狀腺科 | 乳房：乳房硬塊、良性腺瘤、纖維囊腫、乳房疼痛、乳癌、其他乳房疾病、乳房超音波檢查。甲狀腺：甲狀腺結節、良性腫瘤、囊腫、甲狀腺功能亢進、副甲狀腺腫瘤、副甲狀腺功能亢進、其他甲狀腺、副甲狀腺疾病。 |
| 胸腔外科 | 本科專門治療胸腔內臟器有手術適應症的疾病；在肺部方面如：肺部良性或惡性腫瘤、氣胸、膿胸等；縱膈腔方面如：縱膈腔腫瘤、重症肌無力等；食道方面如：食道腫瘤、食道憩室、食道弛緩不能、食道狹窄等。如果您有以下之症狀，如久咳不止、血痰、吞嚥困難、食物或胃酸逆流，建議您到胸腔外科門診接受檢查及後續處置；或者是您在其它醫療院所接受檢查，得知有上述之疾病，而有手術之必要者，亦可至本科求診。 |
| 整形外科 | 各種慢性傷口(糖尿病傷口、下肢潰瘍、褥瘡)。頭頸部腫瘤切除後重建、顏面外傷、顏面骨折、表皮腫瘤、軀體組織缺損重建、手部外科手術、燒燙傷。美容手術：疤痕重整、雙眼皮、眼袋、隆鼻、隆乳、狐臭等等。(限掛醫學美容中心門診) |
| 消化外科 | 胃十二指腸疾病：胃癌、胃腫瘤、胃十二指腸潰瘍合併症、其他胃十二指腸疾病、胃食道逆流疾病。疝氣：鼠蹊部疝氣、股疝氣、臍疝氣、腹疝氣、其他疝氣。肝膽胰疾病:膽結石、膽囊息肉、腫瘤；肝癌、肝腫瘤；膽管結石、胰臟腫瘤；其他肝、膽、胰疾病。外科影像檢查：超音波檢查、電腦斷層檢查、消化道攝影。 |
| 小兒外科 | 疝氣、陰囊水腫、包皮過長、隱睪症、舌繫帶過緊、多指症、泌尿系統先天畸型、斜頸、漏斗胸、消化道先天畸型、無肛症、其他小兒外科相關疾病。 |
